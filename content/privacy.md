WHS is a static website. It does not have accounts, comments, or a newsletter. It does not ask for your name or email.

## What the pages load

Pages are HTML and CSS. Fonts load from Google Fonts, so a request goes to Google when you open a page. If a page links out to another site, that site has its own privacy policy, and it may set cookies after you leave.

The K-pop piece embeds a YouTube music video. Opening that page loads YouTube’s player, which can set cookies and record the view under Google’s policies. Following a link to YouTube does the same once you leave.

There is no analytics script on these pages right now.

## Ads

There is no advertising script on the site yet. WHS is intended to use advertising later. If AdSense is added, Google’s ad code would load in the page, and an ads.txt file would be published at the domain root. That file is not a substitute for the ad code. The meta tag Google sometimes asks for during setup, if you use it, belongs in the page head, not in ads.txt.

## Hosting

If the site is hosted on Cloudflare Pages, Cloudflare may log requests under its own policy, including IP address, as part of serving the files. This site does not run a separate tracker on top of that.

This page will be updated if that changes.
