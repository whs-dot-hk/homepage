WHS is a general site. Pieces are grouped by section. The open section is [K-pop](/kpop/). A new section appears when there is a piece in it, not before.

## Advertising

The site is intended to earn money from advertising. There is no ad script on these pages yet. If AdSense is added, that will be disclosed on the [privacy page](/privacy/).

Google’s verification meta tag, if they ask for one, goes in the page head. An ads.txt file, if they ask for that, is a separate file at the domain root. One does not replace the other, and neither one is the ad code that displays ads.

## What gets a page

A page has to be about something a reader can open: a song, a video, a show, a problem, a tool. [Soyeon’s “Toesa-halgeyo”](/kpop/toesa-halgeyo/) is first because the official music video is public and the joke is specific. Later pieces get in the same way.

There is no contact form and no newsletter. The site is a set of static pages.
